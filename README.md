# 🐘 PostgreSQL — Zero to Hero

A comprehensive PostgreSQL course guide designed for developers transitioning from MongoDB. Covers 25 modules from installation to advanced topics including JSONB, window functions, triggers, Node.js integration, and ORMs.

## What's Inside

- **25 detailed modules** covering everything from basics to advanced
- **MongoDB comparison tables** throughout for easy mental mapping
- **Hands-on SQL examples** for every concept
- **Node.js + Express integration** with `pg` driver
- **ORM guides** for Prisma, Drizzle, and Sequelize
- **Real-world project ideas** to practice
